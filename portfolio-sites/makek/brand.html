07─USAGE GUIDE사용 가이드

하지 말 것, 해야 할 것.

간판은 가맹점주가 직접 변형하지 않습니다. 사이즈·컬러·위치 변경 시 본사 사전 승인이 필요합니다.

DO · 권장

  • 지정된 PANTONE 4종 컬러만 사용 (변환 인쇄 금지)
  • 로고 박스(green)는 비율 유지 후 확대·축소만 허용
  • 외부 배너는 매장 정면 가시 영역에 부착
  • 운영 시간 라벨은 항상 옐로우 배경 + 검정 이탤릭 유지
  • 인쇄·시공물은 본사 발주 채널을 통해서만 진행
  • SNS·POP 사용 시 보조 그래픽 6종을 우선 활용

DON'T · 금지

  • 로고 색상·서체 임의 변경 (그라데이션·외곽선·그림자 추가 금지)
  • 스마일 하트를 다른 색·다른 모양으로 대체 금지
  • OPEN 오벌·CUTE 태그를 90° 이상 회전하여 사용 금지
  • 패널 크기를 임의로 줄여 글자 가독성을 훼손하지 않을 것
  • 외부 배너 배경을 RED 외 다른 색으로 변경 금지
  • 승인 없이 본사 비주얼을 다른 매체에 차용 금지
