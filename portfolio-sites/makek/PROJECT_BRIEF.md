## 8. 로컬 PC에서 이어가는 방법

```bash
# 1. 레포 pull
cd ~/your-local-path/onda-hompage
git pull origin main

# 2. 메이크케이 폴더 진입
cd portfolio-sites/makek

# 3. 클라이언트 자료 확인
ls _assets/client-materials/

# 4. 이 브리프 다시 읽기
cat PROJECT_BRIEF.md

python3 -m http.server 8000
# → http://localhost:8000/portfolio-sites/makek/index.html
```
